# Contributing to The Green Hub

Thank you for your interest in The Green Hub. This document outlines how the team approached development for this coursework project.

## Team Workflow
- All development was carried out using the Agile Scrum methodology
- Tasks were tracked on a Trello sprint board
- Code changes were reviewed before merging into main
- Communication was conducted through Microsoft Teams and group chat

## Development Practices
- Each commit message clearly describes the change made
- Features were broken down into small, testable units
- Manual testing was performed against the live deployed environment before each push

## Reporting Issues
For any questions or to report issues with this project, please contact the Team Binary representatives via the LSBU module forum.
